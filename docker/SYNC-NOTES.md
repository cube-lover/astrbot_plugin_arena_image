## 旧 userscript 可选通道

userscript 兼容源码按既有部署版本保留，并未在此次同步中启用或修复。以下是审阅发现、仍待单独修复的限制，**不要把本次源码同步当作该模式的安全或真实浏览器验收**：

1. 安装脚本包含 relay 的长期共享密钥。现有配置允许 HTTP；公网安装与后续连接必须由管理员使用 **HTTPS** 反向代理保护，不要使用 schema 中的公网 HTTP 示例。HMAC 不加密首次密钥分发。
2. 页面任务的等待超时不等于取消网络请求。原请求可能继续执行；在完成状态未确认时，不应重试生成或评价，也不能把收到超时错误当作上游未执行的证明。
3. reload 指令回执早于实际页面重载完成。失效 Action 的自动恢复可能继续读到旧页面，尚需新页面就绪确认机制。
4. `relay_job_timeout` 未统一限制带显式 timeout 的页面指令；不能将它理解为所有生成任务的硬上限。
5. `relay_allow_ips` 使用字符串前缀而非精确地址/CIDR。需要严格来源限制时使用防火墙或反向代理的精确 IP 规则，不依赖该配置作访问控制边界。

这些问题属于保留的可选通道，不是服务器 `direct` 通道或此次 Chrome/Bridge 维护的修复目标。源码中保留 userscript 支持，不代表建议迁移正在运行的服务器浏览器。
